CE Performance Tracker - Stable Version

Upload index.html, style.css and app.js to your GitHub repository root.

Features:
- Excel upload
- Search by CE name or CE code
- Team filtering
- Weekly ranking
- Monthly ranking
- Overall ranking
- 38 employee master list
- Performance rules

Rules:
7 Day SLM Revisit: 0%, lower is better
CCPDW: 4, higher is better
Re-trip: 0%, lower is better
SLA Response: 100%, higher is better
Utilization: 100%, higher is better
Call Fundamentals: 100%, higher is better
Closed SRs: higher is better
Response Opp: lower is better

The Excel first worksheet is imported. The browser stores imported data locally.
